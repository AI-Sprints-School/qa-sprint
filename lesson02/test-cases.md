# Задание 1.5. Тест-кейсы на форму пополнения

## Классы

Строка на класс или границу: класс — признак разделения — представитель
числом. Границы записываются числами (`0,01`, `100000`), а не словами.
Числовые требования лежат на странице `/tariffs`.

## Тест-кейсы

Не больше восьми строк. Каждый класс из раздела «Классы» закрыт ровно
одним кейсом; повторов в колонке «Что закрывает» нет. Ожидаемый результат
берётся из требований, а не из того, что показал продукт, и он один
на кейс. Баланс в предусловии записывается числом до прогона.

| # | Название | Предусловие | Шаги | Ожидаемый результат | Что закрывает |
|---|---|---|---|---|---|
|  |  |  | 1.<br>2.<br>3. |  |  |

## Расхождения

Строка на каждый кейс, который не сошёлся: номер кейса, что ожидалось
по требованию, что фактически показал продукт. Ожидание в самом кейсе
при этом не переписывается. Расхождений может не быть — тогда так
и напишите одной строкой.
