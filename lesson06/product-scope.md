# Границы «Кошелька»: что в продукте есть и чего в нём нет

**Этот файл открывается после того, как сырой вывод модели закоммичен.**
Открыв его раньше, вы перепишете границы в промпт, и достраивать модели
станет нечего.

Слева — то, что в продукте действительно есть и что можно открыть.
Справа — то, чего в нём нет ни на одной поверхности: ни экрана, ни
эндпоинта в документации API, ни строки на странице «Тарифы и правила».
Правая колонка — не полный список несуществующего, а те достройки,
которые модели предлагают чаще всего.

| Что есть | Чего нет |
|---|---|
| Вход по логину и паролю, выданным школой | Регистрации, восстановления пароля, входа по PIN или отпечатку |
| Баланс на главном экране | Нескольких счетов, кошельков в разных валютах, конвертации валют |
| Пополнение своего счёта (`/topup`) | Перевода другому пользователю: поля получателя нет ни на одном экране |
| Списание со своего счёта (`/withdraw`) | Оплаты по QR-коду, оплаты по реквизитам, платежей по шаблону |
| Комиссия за списание: 1,5%, минимум 10 ₽ | Кэшбэка, бонусов, начисления процентов на остаток |
| История операций с фильтром по типу (`/history`) | Выписки в PDF, выгрузки в файл, отправки истории на почту |
| Страница «Тарифы и правила» (`/tariffs`) | Смены тарифа из интерфейса |
| REST API с документацией (`/docs`) | Эндпоинтов про переводы, карты, QR, лимиты по времени |
| Чат-ассистент: отвечает на вопросы о вашем кошельке. Его ответы вы будете сверять с базой — позже в спринте | Голосового ввода, ассистента, который сам выполняет операции |
| SQL-консоль только на чтение (`/sql`) — служебное окно в ту же базу | Изменяющих запросов: `INSERT`, `UPDATE`, `DELETE` консоль отклоняет |
| Мобильная поверхность: тот же «Кошелёк» на узком экране | Привязки банковской карты, платёжных систем, любых внешних интеграций |
| Две сборки клиента: рабочая и регрессионная (глава 10) | Push-уведомлений, писем о совершённых операциях |

## Как доказывается отсутствие

Отсутствие доказывается местом, где функция была бы, если бы существовала:

- функция интерфейса — экран, на котором она стояла бы: `/topup` для
  перевода, `/withdraw` для оплаты по реквизитам;
- функция сервера — документация API по адресу `/docs`: там перечислены
  все эндпоинты, которые есть;
- условие или лимит — страница `/tariffs`;
- поведение ассистента — окно чата: спросите и посмотрите, что он ответит.

В разделе «Что AI выдумал» по каждому пункту называется конкретное место
и то, что вы там увидели. Спор с моделью доказательством не является
ни с одной стороны: решает продукт.
